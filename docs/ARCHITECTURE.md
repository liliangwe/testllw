# 组织架构与人员管理系统 架构文档

## 1. 模块 overview

本系统为组织架构与人员管理模块，采用单体 Spring Boot 应用，按业务领域划分为三个核心模块：

| 模块 | 职责 | 说明 |
|------|------|------|
| 部门模块 | 部门树维护、层级移动、删除校验 | 支持懒加载、防循环引用拖拽 |
| 员工模块 | 员工增删改查、调动、离职、唯一性校验 | 乐观锁控制并发调动 |
| 调动记录模块 | 记录员工调动历史 | 被员工模块依赖 |

## 2. 应用分层

```
com.example.organization
├── controller    # Web 层 / REST API
├── service       # 业务服务层
│   └── impl
├── dao           # 数据访问层
│   └── mapper
├── model         # 数据模型
│   ├── entity    # DO
│   ├── dto       # VO / DTO
│   └── request   # 请求对象
├── integration   # 外部服务客户端
└── common        # 公共类
```

## 3. 依赖关系

- Web 层 → Service 层 → DAO 层
- 员工模块 → 部门模块（查询部门存在性）
- 员工模块 → 调动记录模块
- 员工模块 → 审批流/权限服务客户端

## 4. 约束

- 统一返回 `ApiResponse<T>`
- 统一使用逻辑删除（`is_deleted`）
- 乐观锁字段 `version` 控制并发更新
