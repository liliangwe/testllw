# quicksort 模块

## 职责

提供标准快速排序算法实现，对 int 数组进行原地升序排序。

## 关键类

| 类 | 职责 |
|----|------|
| QuickSort | 快速排序工具类（final + 私有构造），提供静态 `sort(int[])` 方法 |
| QuickSortTest | 单元测试，覆盖正常路径、边界值、异常路径、大数组回归 |

## 算法说明

- 分区方案：Lomuto 分区
- 基准值选取：区间最右元素
- 时间复杂度：平均 O(n log n)，最坏 O(n²)
- 空间复杂度：O(log n)（递归栈）

## 依赖

无外部依赖，纯 JDK 标准库。
