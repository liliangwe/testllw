# Plan: 创建待办事项（最小闭环）

## 需求
- 目标：帮助内部用户记录日常待办事项。
- 核心功能：**新增待办事项**（仅创建，不做查询/更新/删除）。
- 任务信息字段：事项名称（title）、事项描述（description）。
- 目标用户：内部用户。
- 最小闭环：仅创建。

## Global Constraints（绑定要求，逐字）
1. 事项名称（title）为必填，去除首尾空白后不得为空字符串；为空时抛出 `ValueError`。
2. 事项描述（description）为可选项，默认值为空字符串 `""`。
3. 每个新建待办事项必须生成唯一标识 id（使用 UUID 字符串）。
4. 新建的事项必须被持久化到服务内部的内存存储中（服务实例持有列表）。
5. 除「创建」外不得实现其他 CRUD（如更新、删除、查询接口），保持最小闭环 YAGNI。
6. 技术栈：Python 3 标准库（无第三方依赖、无网络、无数据库）。

## 涉及文件
- `todo.py`：新建，包含 `Todo` 数据类（id/title/description）与 `TodoService`（`create` 方法）。
- `test_todo.py`：新建，标准库 `unittest` 单测。

## 任务拆分
- Task 1：实现 `todo.py` + `test_todo.py`，并通过全部单测（唯一任务）。
