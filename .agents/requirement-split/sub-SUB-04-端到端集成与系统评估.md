# SUB-04：端到端集成与系统评估

## 结果 / 用户价值
将数据感知、边缘预测、实时调度、联邦学习协同整合为一个可运行的分布式能效管理系统，并输出综合评估报告，验证系统整体价值。

## 范围与仓库影响
- **系统集成层**：
  - 新增统一接口定义和编排模块，串联 SUB-01/02/03。
  - 新增仿真环境或接入真实硬件的集成脚本。
  - 新增演示和可视化界面（CLI/Web/Notebook 均可）。
- **系统评估**：
  - 新增综合评估框架，覆盖预测精度、调度收益、实时性、隐私、碳排放等指标。
  - 新增实验报告模板和自动化报告生成脚本。
- **仓库影响**：
  - 新增 `integration/` 目录：接口定义、编排、部署脚本。
  - 新增 `evaluation/` 目录：综合评估指标、报告生成。
  - 新增 `demo/` 目录：演示脚本或最小可视化界面。

## 验收标准
1. 端到端 demo 可在仿真环境或真实节点上运行。
2. 完整流程（数据采集 → 预测 → 调度 → 联邦协同）可演示。
3. 综合评估报告覆盖以下维度：
   - 预测精度（MAPE/RMSE/R²）
   - 调度收益（成本降低、碳排放降低）
   - 实时性（推理延迟、调度求解延迟）
   - 隐私（差分隐私参数、攻击成功率）
4. 关键接口和模块间契约文档化。

## 依赖
- **SUB-01（阻塞）**：需要预测基线。
- **SUB-02（阻塞）**：需要调度策略。
- **SUB-03（阻塞）**：需要联邦学习协同。

## 测试证据
- 集成测试：模块间接口调用正确。
- 端到端测试：完整流程运行无异常。
- 演示验收：可运行 demo 并展示关键指标。
