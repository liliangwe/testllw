# SUB-02：实时动态调度策略

## 结果 / 用户价值
基于 SUB-01 的预测结果，实时优化储能电池充放电策略及可控负载（如电动汽车充电桩、空调）的运行状态，以最小化整体能耗成本和碳排放。

## 范围与仓库影响
- **决策优化层**：
  - 新增储能电池模型（SOC、充放电效率、寿命约束等）。
  - 新增可控负载模型（充电桩、空调等柔性负载）。
  - 新增 MILP 调度求解器模块，处理线性约束下的全局优化。
  - 新增强化学习（RL）调度模块，处理动态、非线性场景。
  - 新增 MILP + RL 混合策略编排模块。
- **对接 SUB-01**：
  - 通过定义好的接口获取发电/用电预测结果。
  - 将调度决策反馈给仿真环境或实际控制执行单元。
- **仓库影响**：
  - 新增 `optimization/scheduler/` 目录：调度模型、求解器、策略。
  - 新增 `tests/scheduler/` 目录：场景测试和对比基准测试。

## 验收标准
1. 调度策略在仿真环境中运行稳定，无异常中断。
2. 相比基线策略（如固定阈值、规则基线），能耗成本降低 ≥ 约定比例，或碳排放降低 ≥ 约定比例。
3. 动态场景下，调度求解延迟满足实时性要求（具体毫秒/秒数待确认）。
4. 支持储能 SOC、负载功率等关键约束不被违反。

## 依赖
- **SUB-01（阻塞）**：需要预测模块输出作为调度输入。

## 测试证据
- 仿真场景对比测试：与基线策略在多种典型场景下对比。
- 边界条件测试：极端天气、高负荷、储能满载/空载等场景。
- 性能基准测试：求解延迟、内存占用。
