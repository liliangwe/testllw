## 1. 需求概述

### 1.1 背景与目标

构建一个**人员看板（Staff Board）**，用于集中维护员工档案信息，支撑团队人力与成本管理场景。看板提供员工基本信息的录入入口，支持对员工档案的增删改查（CRUD），并支持批量导入；同时记录每名员工的**成本预算**，并对导入操作施加**白名单**与**批量导入**约束。

### 1.2 需求原文拆解

原始需求：`开发一个人员看板，有入口记录员工的基本信息以及增删改查，支持导入以及记录成本预算--白名单、批量导入`

拆解为如下能力点：

| 能力点 | 说明 |
|--------|------|
| 看板展示 | 以列表/表格形式展示人员档案总览 |
| 录入入口 | 提供新增员工基本信息的入口 |
| 基本信息 CRUD | 增、删、改、查员工基本信息 |
| 导入 | 支持批量导入员工信息 |
| 成本预算 | 记录每名员工的成本预算 |
| 白名单 | 对特定能力（导入/高成本操作）施加白名单控制 |
| 批量导入 | 支持一次性导入多名员工 |

### 1.3 目标用户

- 人力/行政或团队管理者：维护员工档案与成本预算
- 有白名单权限的运营人员：执行批量导入

## 2. 术语与概念

| 术语 | 定义 |
|------|------|
| 员工（Staff） | 人员看板中的一条档案记录，含基本信息与成本预算 |
| 基本信息 | 姓名、工号、部门、岗位、邮箱、入职日期等员工基础字段 |
| 成本预算（Cost Budget） | 员工对应的预算金额/周期，用于人力成本核算 |
| 白名单（Whitelist） | 允许执行受限操作（如批量导入）的用户/账号集合 |
| 批量导入（Bulk Import） | 通过文件一次性写入多条员工档案 |

## 3. 功能需求

### F1 人员看板展示
- 看板以分页列表展示员工档案。
- 支持按姓名、工号、部门等条件检索/筛选。
- 看板汇总可展示在册人数、预算总额等概览指标。

### F2 员工基本信息录入入口
- 提供“新增员工”入口表单。
- 必填字段：姓名、工号（唯一）；其余字段按需填写。
- 保存后进入员工列表并返回创建结果。

### F3 员工基本信息 CRUD
- **增（Create）**：新增员工档案。
- **删（Delete）**：删除员工档案；删除前需二次确认；已删除记录不参与看板汇总。
- **改（Update）**：编辑员工基本信息与成本预算。
- **查（Read）**：单条详情查询 + 列表分页/条件查询。

### F4 成本预算记录
- 每名员工关联一条成本预算记录（金额 + 周期，如月度/年度）。
- 支持在看板中显示单员工预算与看板预算汇总。
- 预算随员工档案录入或编辑时维护。

### F5 导入（批量导入 + 白名单）
- 支持通过上传文件（Excel/CSV）批量导入员工档案与成本预算。
- 导入需携带校验：工号唯一性、必填字段、预算字段格式。
- **白名单**：批量导入仅对白名单用户开放；非白名单用户导入请求被拒绝。
- 导入结果返回成功条数、失败条数及逐行失败原因。

## 4. 业务规则与约束

| 编号 | 规则 |
|------|------|
| R1 | 工号在系统内唯一，重复工号拒绝新增/导入 |
| R2 | 姓名、工号为必填字段 |
| R3 | 成本预算金额为非负数值，周期枚举可配置 |
| R4 | 批量导入必须命中白名单，否则拒绝 |
| R5 | 删除为逻辑删除，保留审计可追溯 |
| R6 | 批量导入需整体可回滚或逐行原子提交（单行失败不影响其它行） |

## 6. 接口契约（草案）

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 员工列表 | GET | /api/staff | 分页 + 条件查询 |
| 员工详情 | GET | /api/staff/{id} | 单条查询 |
| 新增员工 | POST | /api/staff | 创建员工及预算 |
| 更新员工 | PUT | /api/staff/{id} | 编辑基本信息与预算 |
| 删除员工 | DELETE | /api/staff/{id} | 逻辑删除 |
| 批量导入 | POST | /api/staff/import | 白名单校验 + 文件解析 |

## 7. 非功能要求

- 数据持久化，删除/导入操作可审计。
- 批量导入单次规模上限与超时控制（建议单次 1000 条，可配置）。
- 白名单校验失败返回明确错误码。
- 看板列表查询走索引（工号、部门维度）。

## 8. 范围边界（Exclude / 待确认）

### 8.1 排除范围
- 不实现员工考勤、绩效、薪资发放。
- 不实现登录认证体系的完整改造（复用现有认证，白名单在现有体系上叠加）。

| 编号 | 内容 | 当前假设 | 状态 |

## 9. 待评审问题清单

1. 白名单的范围：仅约束“批量导入”，还是也约束“成本预算”的录入/修改？

3. 批量导入模板字段是否包含成本预算，还是两阶段（先导入基础信息、再补预算）？
