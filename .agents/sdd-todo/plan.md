# 创建待办事项 — 实现计划

## 需求
- 目标：帮助用户记录日常待办事项，目标用户为内部用户。
- 核心功能：新增待办事项。
- 事项信息：名称（name）与描述（description）。
- 最小闭环：仅创建（不涉及修改/删除/完成/持久化）。

## 技术栈与约束（Global Constraints）
- 语言：Java（与仓库既有 HelloWorld.java 一致；默认包，无第三方依赖）。
- 无持久化、无数据库、无 Web、无并发。
- 仅实现「创建」闭环，遵守 YAGNI。
- 禁止任何 Git 写操作（提交、推送等）；只写入源码/文档文件。
- 验证：环境无 JDK 工具链时，采用静态代码审查并说明；同时提供可在有 JDK 环境下运行的 main 演示入口。

## 任务拆解
- Task 1：实现待办事项模型与新增能力（TodoItem + TodoList + 入口演示）。
